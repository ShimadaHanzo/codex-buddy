# 安全反馈 / Security

请勿在公开 Issue 中粘贴登录文件、令牌、私人路径或真实额度截图。普通问题请提供版本、macOS 版本、芯片类型和脱敏复现步骤。

For ordinary bugs, share the app version, macOS version, architecture, and sanitized reproduction steps. Never attach authentication files, tokens, private paths, or real account screenshots.

发现漏洞时优先使用仓库 Security → Report a vulnerability（仅在维护者启用后可用）。如入口不可用，请开一个不含漏洞细节的 Issue 请求私密反馈渠道，不要公开利用步骤或秘密数据。

For vulnerabilities, use Security → Report a vulnerability if enabled. Otherwise request a private reporting channel in an issue without disclosing exploit details or sensitive data.
